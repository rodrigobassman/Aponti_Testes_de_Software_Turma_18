O que é teste de software

É um controle de qualidade com o objetivo de identificar possíveis falhas de um sistema ou componente. Testar é muito importante para evitar prejuízos financeiros, pois é mais barato corrigir um erro enquanto o sistema está sendo desenvolvido. Tem também o fator segurança, a fim de evitar vulnerabilidades e expor dados sensíveis.
A qualidade e experiência também são fatores importantes, pois garantem que o aplicativo não vai travar enquanto o cliente usa.

Existem dois grandes tipos de testes:

Manual: O testador assume o papel do usuário final e tenta "quebrar" o sistema para ver como ele reage.

Teste Automatizado: são programas e scripts de código para testar o próprio software. É ideal para tarefas repetitivas.

Por que testar é importante para o negócio

Quando o código falha, além do prejuízo financeiro, põe em risco a reputação da empresa. O custo envolve parar as atividades para refazer o código sob pressão. Além disso, vazamentos de dados podem falir uma empresa e também evita o lançamento de um código inacabado.

O que caracteriza um software com qualidade
Implica dizer que a aplicação é segura, fácil de usar, tem bom desempenho, faz aquilo que se propôs a fazer. compatibilidade, confiabilidade.

Qual o papel do QA em um time moderno

evita o erro antes de que ele aconteça. ensinar o time, automatizar, garantir que a aplicação seja fácil, rápida e segura para quem vai usar.
