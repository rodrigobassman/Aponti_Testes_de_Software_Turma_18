# Atividade Avaliativa: Fundamentos de Teste e Qualidade de Software

---

## O que é teste de software?
É um controle de qualidade com o objetivo de identificar possíveis falhas de um sistema ou componente. Testar é muito importante pelos seguintes motivos:

* **Prevenção de prejuízos financeiros:** É muito mais barato corrigir um erro enquanto o sistema ainda está sendo desenvolvido.
* **Segurança:** Evita vulnerabilidades que possam expor dados sensíveis.
* **Qualidade e experiência:** Garante que o aplicativo não vai travar enquanto o cliente o utiliza.

---

## Os dois grandes tipos de testes

* **Manual:** O testador assume o papel do usuário final e tenta "quebrar" o sistema para ver como ele reage.
* **Automatizado:** São programas e scripts de código criados para testar o próprio software. É o modelo ideal para tarefas repetitivas.

---

## Por que testar é importante para o negócio?
Quando o código falha, além do prejuízo financeiro direto, a empresa põe em risco a sua própria reputação. O custo de um erro em produção envolve parar as atividades da equipe para refazer o código sob pressão. 

Além disso, os testes evitam o lançamento de um produto inacabado e protegem o negócio contra vazamentos de dados, que podem levar uma empresa à falência.

---

## O que caracteriza um software com qualidade?
Implica dizer que a aplicação atende aos seguintes pilares:
* **Segurança** e proteção de dados.
* **Usabilidade** (fácil de usar).
* **Desempenho** (rápido e estável).
* **Adequação funcional** (faz exatamente aquilo que se propôs a fazer).
* **Compatibilidade** com diferentes ambientes.
* **Confiabilidade** no dia a dia.

---

## Qual o papel do QA em um time moderno?
O analista de QA (Quality Assurance) hoje atua de forma estratégica no time para:

> 🎯 **Evitar o erro antes que ele aconteça.**

* **Ensinar o time:** Disseminar a cultura de qualidade entre todos os membros.
* **Automatizar:** Criar rotinas automáticas de testes para dar agilidade.
* **Advogar pelo usuário:** Garantir que a aplicação seja fácil, rápida e segura para quem vai usar.
